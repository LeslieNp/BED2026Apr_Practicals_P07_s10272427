QnA
a. Why use POST for creating resources and PUT for updating?
POST is used when creating a new resource because the server generates and stores a new entry based on the data that we sent. 
PUT is used when updating because it modifies an existing resource using its ID. 
In conclusion, Post is for adding stuff and Put is used when we want to edit the stuff

b. What status code should be returned when attempting to update a non-existent resource
The correct status code is 404 Not Found because the resource does not exist on the server, so it cannot be updated.
When I was doing the class work, my Postman kept showint 404, hence I knew my resource did not exist on the server,
not allowing the system to register and update it.
